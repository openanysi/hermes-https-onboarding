# Dashboard screenshots

These are the two user-supplied reference screenshots showing the Hermes v0.23.1 Dashboard. The original pixels and existing red annotations are preserved.

- `hermes-channels-api-server.png`: Channels page, API server enable toggle and Configure button.
- `hermes-api-server-settings.png`: API Server configuration dialog, enable field, masked auth key and Save & Enable button.

The guides use the same images with English or Chinese explanatory text. Connection states in these examples are not proof of a reader's server status. Password dots and redacted placeholders are not real values to enter. No new live Dashboard session was captured for this documentation update.
